# Attack Simulation

## Overview

This document describes the cyber attack simulations performed in the SIEM Detection Lab.

The purpose of these simulations is to generate security events and verify that Wazuh correctly detects, logs, and alerts on suspicious activities.

---

## Planned Simulations

- Port Scan (Nmap)
- Brute Force Login
- PowerShell Execution
- File Integrity Monitoring
- Suspicious Process Execution
- Registry Modification
- Persistence Techniques

---

## Documentation Format

Each attack will include:

- Objective
- Attack Description
- Commands Used
- Detection Rule
- Alert Level
- MITRE ATT&CK Technique
- Wazuh Dashboard Screenshot
- Investigation Notes
